# صفحات خطای مشاهیر

فایل‌های این پوشه:
- 400.php
- 401.php
- 403.php
- 404.php
- 429.php
- 500.php
- 502.php
- 503.php
- 504.php
- error.css
- error-bg.jpg

تمام صفحات از error.css و error-bg.jpg مشترک استفاده می‌کنند.

نکته:
در فایل‌های PHP مسیر دکمه «صفحه اصلی» فعلاً ../index.php است.
اگر محل قرارگیری صفحات Error متفاوت است، فقط href همین دکمه را اصلاح کن.

برای نمایش:
http://localhost/Kavian/.../404.php
